This project focuses on building effective and structured prompts for Generative AI in the aviation industry. The main objective is to understand how a well-designed prompt can improve the quality, accuracy and usefulness of AI-generated responses. The activity is based on four essential prompt ingredients: Task, Context, Constraints and Output Format.

The project first explains the role of each ingredient. The Task tells the AI what to do, Context provides relevant background information, Constraints define rules and limitations, and Output Format specifies how the final response should be presented. Examples include creating passenger emails, SMS messages, reports, tables, airport announcements and presentation outlines.

A vague flight-delay prompt is first tested to identify missing information such as flight details, delay duration, reason, revised timing, passenger instructions, tone and word limit. This output is then compared with a structured prompt using a realistic aviation scenario involving Flight AV205 from Delhi to Mumbai. The structured prompt includes verified details, clear instructions, limitations and a specific format.

The project also covers a messy business request related to baggage complaints. This request is converted into a structured prompt that classifies complaints, identifies common concerns and provides practical improvement suggestions without inventing information.

Students also create two original aviation prompts, participate in peer review, revise their prompts based on feedback and conduct a one-variable test by changing only one prompt component at a time.

Overall, the project demonstrates that clear prompting helps AI understand the business requirement better and produce more useful outputs, while human review is still required to check factual accuracy and business suitability.
